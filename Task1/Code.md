Case Study 91: Advanced String-Based Registration Record Analyzer
1. Problem Statement
Develop a Python program to analyze student registration records stored as strings. Validate field lengths and formats, extract student details, identify duplicate registration IDs, and classify invalid records based on errors.
2. Algorithm
1. Start the program.
2. Store registration records in a list.
3. Split each record using commas.
4. Check whether the record contains four fields.
5. Validate student ID, name, branch, and year.
6. Check for duplicate student IDs.
7. Store valid records separately.
8. Display valid records, duplicates, and error classifications.
9. Stop.
